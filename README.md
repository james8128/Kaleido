# Kaleido

A demo hobby kaleidoscope (萬花筒) built with Grok App Builder. For interest and record only — not an active product.

Move the pointer or a finger; strokes are mirrored into radial symmetry. Traditional Chinese UI.

- Segments: 3–18
- Palettes: 棱鏡, 燻火, 潮汐, 墨白, 花開, 林間
- Freeze, randomize, export PNG, clear
- Shortcuts: Space freeze, R randomize, E export, C clear

Settings (segments + palette) persist in `localStorage`. No accounts, no backend.
